왜 다시 짜는가

1순위는 인력 충원, 2순위는 업무 프로세스 개선으로 업무 강도와 압박을 없앰.

우선순위. 업무 효율과 매니저 개개인의 생활·컨디션을 동시에 중시
  • 시간을 사람에게 맞추지 않고, 사람을 시간에 배치함
    • 오전 10시 리스트와 저녁 접수는 야근·주말 근무가 아니라 시차 출근과 오후 전담으로 해결
    • 매니저 개개인의 정시 퇴근 보장
    • 퇴근 이후에는 업무와 분리, 업무 연락 없음
    • 주말도 업무와 분리, 매니저 전원 휴무로 개인 생활 존중 (본인 실수 건 수습만 예외)
    • 과도한 리뷰어 문의로 힘들던 부분은 인력 충원 후 캠페인을 나눠 맡는 것으로 대체해 1인당 문의량 감소

도입 여부. 도입은 확정이 아님. 5명 체제가 완료된 뒤 업무 프로세스상 필요하거나 주말에 사건이 계속 터지거나 해결할 일이 생길 것 같다고 판단되면 도입. 토요일 당직 체제는 5명 체제 확정 후 정함. 아래는 도입할 경우의 운영안. 당직 시간은 약 3시간 내외로, 매달 C/S 문의가 집중적으로 몰린 시간을 보고 정하며, 그 달에는 정한 시간으로 고정하고 다음 달에는 다시 그 달의 몰린 시간을 보고 새로 정함. 당직 다음 주 평일 화~목 중 하루를 정해 3시간 늦게 출근. 팀장은 평일 근무를 뺄 수 없어 당직 순번에 들어가지 않음. 당직을 서지 않더라도 주말 매니저 사고 건에 대비해 핸드폰은 항시 ON.

1 사고 확인자동구매 오류 문자·구매 중단 건 확인, 사고 확산 차단물량 사고가 번지는 경우에만 일시정지 후 담당자 메모·팀장 보고. 수정은 월요일 담당자
2 본인 계정당직자 본인 담당 캠페인의 금요일 저녁~토요일 진행분 영수증 승인, C/S 처리체크 7항목 그대로
3 다른 매니저 계정본인 건을 끝내고 시간이 남으면 다른 매니저 계정에 들어가 영수증 승인·C/S를 이어가며 당직 시간 채움판단이 애매한 건(가격·옵션 차이, 반려)과 캠페인 정보 수정·재세팅은 손대지 않고 담당자 메모
4 마무리처리 내역 정리, 팀장 보고, 담당자별 인계 메모다른 매니저 계정에서 처리한 건은 월요일 담당자에게 목록으로 공유. 정해진 당직 종료 시각에 종료

당직자도 영업자·업체 응대, 신규 접수, 캠페인 정보 변경, 리스트 송부, 리뷰어 문의는 하지 않음. 당직자 외 매니저는 주말에 업무가 없다는 기준은 당직을 도입해도 같음. 일요일에는 당직이 없고, 일요일 진행분은 월요일에 각 담당 매니저가 승인. 팀장은 평일 근무를 뺄 수 없어 당직 순번에 들어가지 않음. 당직을 서지 않더라도 주말 매니저 사고 건에 대비해 핸드폰은 항시 ON.

대체일은 다음 주를 넘기지 않음. 대체일과 연차가 겹치면 대체일을 다른 요일로 옮김.

인원별 토요일 당직 커버리지 (도입 시 예시)

주차는 순번 한 바퀴를 보여 주는 예시. 실제 순번과 대체 요일은 매월 1일 월 근무표에서 확정. 대체일은 화·수·목을 돌아가며 잡아 같은 요일에 몰리지 않게 함. 팀장은 평일 근무를 뺄 수 없어 당직 순번에 들어가지 않음. 당직을 서지 않더라도 주말 매니저 사고 건에 대비해 핸드폰은 항시 ON.

당직 순번 규칙 (도입 시)

  • 당직은 매니저 전원이 순번으로 섬. 오전조·주간조·오후 전담 구분이 없음. 팀장은 평일 근무를 뺄 수 없어 당직 순번에 들어가지 않음. 당직을 서지 않더라도 주말 매니저 사고 건에 대비해 핸드폰은 항시 ON.
  • 당직 시간은 달마다 정함. 그 달에는 정한 시간으로 고정하고, 다음 달에는 다시 C/S가 몰린 시간을 보고 새로 정함
  • 당직자는 본인 계정 업무를 끝낸 뒤 시간이 남으면 다른 매니저 계정 업무를 이어가며 당직 시간을 채움
  • 당직 다음 주 평일 화~목 중 하루를 정해 3시간 늦게 출근
  • 순번은 매월 1일 월 근무표와 함께 확정. 주차별 당직자와 대체일을 같은 표에 적음.
  • 순번을 맞바꿀 때는 당사자끼리 합의하고 팀장 승인을 받음. 대체일도 함께 옮김.
  • 당직일에 연차를 쓰면 다음 순번과 맞바꿈. 빠진 순번은 다음 달 첫 주에 채움.
  • 입사 8주 이내 신입은 순번에서 빠짐. 사고를 혼자 판단해야 하는 자리이기 때문.

배분 전 가이드 검수 8항목

  1. 구매요청 시간
    시간대가 현실적인지, 건수 대비 너무 짧지 않은지. 점심시간·퇴근 후 모집 요구는 커트
  2. 구매 건수
    일일·총 건수가 상품·플랫폼 기준으로 소화 가능한지
  3. 리스트 송부 시간
    당일분은 퇴근 직전까지 송부하는 기준에 맞는지. 개별 시각 요구는 영업자에게 안내 후 조정
  4. 상품 링크
    정상 연결, 옵션 일치, 기존 진행 이력(묶음 판단)
  5. 상품 가격
    가이드 금액과 실판매가 일치, 가격변동 여부(20% 초과 불가)
  6. 배송 형태
    실배송 · 가배송 · 가송장 · 회송 중 명확한지
  7. 입금 형태
    입금대행 · 업체입금 · 파일리스트방 전환 여부, 입금자명
  8. 리뷰 조건
    리뷰비, 원고(텍스트 .txt + 포토 넘버링, 엑셀 반려), 키워드, 포토·동영상 특이사항
오류가 있으면 배분하지 않음. 영업자·접수 담당자에게 수정 요청하거나 반려 후 재기안을 받음.

접수 불가 · 반려 기준

접수 불가

  • 가격변동 캠페인을 가송장(직접전달)으로 진행하는 건
  • 가격변동 폭 20% 초과 (가격변동 자체를 받지 않는 것이 가장 안전)
  • 병원·보험 앱 리뷰, 경쟁사 악평·별점 하락 요청
  • 리뷰어 수요가 없는 플랫폼(지도 앱 등), 상담 결제 구조 플랫폼
  • 실배송 동영상 리뷰는 기본 프로세스 아님, 가배송 동영상은 원고 수령 시 소량만

반려 후 재기안

  • 자동구매·일반구매 모두 상신이 올라온 시각에 비해 구매요청 시간이나 리스트 송부 시각이 타이트한 건
  • 원고를 엑셀로 접수, 캠페인명·옵션·기획전 링크 누락
  • 파일만 보내고 상신 없이 배분 요청 (팀장 컨펌 없이는 진행 금지)

새로 추가되는 기준

  • 주말 진행 요청은 금요일 접수 마감까지만 접수. 금요일 이후 들어온 주말 건은 월요일 접수
  • 3명 체제는 접수 마감 18:00 하나로 운영, 4명 체제부터 17:30·19:00 두 번.
  • 영업부 팀장의 일반구매 직접 등록: 11월 현재 영업부 팀장들이 일반구매를 직접 등록 중. 11월까지만 직접 등록하며, 12월부터는 직접 등록 폐지

분배 원칙과 절차

  1. 상신·톡방에서 신규 캠페인 링크 확인
  2. 업무분장(굿투 확인용)에서 담당자·업체 매핑 확인
  3. 관리자 계정에서 링크·업체명 검색, 이전 진행 이력과 담당자 확인
  4. 기존 담당자 가능 여부 확인, 불가 시 컨디션 보고(이름 / 진행 캠페인 수 / 역량 %) 기준으로 대체
  5. 결재 댓글에 "OO 진행" 기재 후 승인
  6. 배분 톡방에 담당자 태그
우선순위. 업무분장 매핑 → 기존 담당자 → 가용량(컨디션). 신규 영업자의 리뷰 요청 건은 해당 영업자가 업무에 익숙해질 때까지 팀장이 실무 담당.

시간대 고려 (신규)

  • 배분할 때 시간대 매핑을 함께 봄. 아침 리스트가 빨리 나가야 하는 캠페인은 오전조, 저녁 진행이 잦은 업체는 오후 전담에게 매핑. 오전 리스트가 필요한 캠페인은 오후 전담에게 매핑하지 않음
  • 4명 체제부터 17:30 이후 접수 중 신규 업체 건은 오후 전담 담당으로 배분. 기존 담당자가 있는 업체 건은 오후 전담이 일시정지 상태로 등록만 해 두고, 익일 담당 매니저가 검수·라이브·승인·리스트를 맡음
  • 신규 업체 톡방 개설 시 헤더와 굿투그레이트 본사 계정 두 개 모두 무조건 초대

광고주 URL 운영 (마감 후·주말 현황 확인 수단)

퇴근 후와 주말에는 리스트를 송부하지 않으므로, 영업자가 진행 현황을 스스로 확인할 수 있어야 함. 영업자별 공통 URL에 당일 접수 캠페인을 전부 넣음.

운영

  • 신규 영업자 URL 최초 생성은 팀장
  • 당일 접수분은 퇴근 전 전부 추가, 익일로 넘기지 않음
  • 마감 후 접수분도 팀장이 직접 추가 (해당 계정은 팀장만 사용 가능)
  • 에이전트 계정으로만 추가

안내 문구

  • 현황 확인 용도로만 사용
  • 영수증 승인 전 리스트 다운로드 금지 (다운로드 시 캠페인 사고로 간주)
  • 설정 변경 금지
  • 캠페인은 같은 링크에 누적 추가

영수증 승인 체크 7항목

  • 상품 일치: 캠페인 업체 상품, 상품명·옵션이 가이드와 같은지
  • 금액 일치: 총 결제금액이 가이드 또는 요청 금액과 같은지
  • 주문번호: 정상 기재, 오류·누락·-1 예외 확인
  • 포인트 결제 금지: 쿠팡캐시·네이버포인트 사용 시 반려
  • 쿠폰 캠페인: 가격변동 건이면 실결제 금액으로 가격변경 승인
  • 배송 유형: 로켓 아닌 캠페인의 로켓 구매는 반려 후 재구매
  • 반려 시 사유 입력 필수

리스트 송부 전 체크 6항목

  • 잔여 건수 처리 방향: 익일 이월 vs 고정 (이월 시 건수 재세팅)
  • 가격 변동 캠페인은 금액 수기 수정 후 승인
  • 영수증 승인 완료, 미승인 건 0
  • 주문번호 정상, 타 플랫폼 유형 섞임 없음
  • 구매 대기자 독촉 또는 참여 취소
  • 다운로드~송부 사이 추가 구매 방지, 파일 열어 최종 확인
